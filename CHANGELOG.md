# Changelog

## 1.1.0 (2026-10-12)

### Added
- Settings: typed settings with search, per-group reset, Basic / Advanced split.
- Appearance: light / dark / AMOLED, accent colours, corners, density, fonts.
- Playback: equalizer, bass / loudness boost, crossfade, ReplayGain, A-B repeat, queue restore.
- Notification: favourite (heart) button next to the playback controls, with a setting to hide it.
- Gestures settings group (mini player swipe, haptics).
- Backup & restore of settings, favourites, playlists and hidden songs (JSON file).

### Fixed
- Release builds crashing on the first notification (shrunk notification icons).

## 1.0.0 (2026-10-11)
- First release: offline library, player, playlists, favourites, search; uz / ru / en.
